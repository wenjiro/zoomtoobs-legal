ZoomToOBS Support

ZoomToOBS bridges Zoom meeting video to OBS Studio via Spout on Windows.

Email support:
wenjiro@gmail.com

Before contacting support

  • Check the documentation for setup steps.
  • Regenerate sdk_jwt if authentication fails.
  • Ensure the meeting host approved local recording.
  • Install obs-spout2-plugin for OBS.

Common issues

  • SDK authentication failed — regenerate JWT with your Zoom Client ID and Secret.
  • Cannot join external meeting (error 63) — app must be approved on Zoom Marketplace.
  • No video — host must allow local recording; select participants and click Apply.
  • Spout not visible in OBS — install obs-spout2-plugin and run ZoomToOBS before adding sources.
