ZoomToOBS — User Guide

How to set up, use, and remove ZoomToOBS with Zoom and OBS Studio on Windows.

1. Adding ZoomToOBS

Requirements

  • Windows 10 or 11 (64-bit)
  • Zoom Meeting SDK app credentials (Client ID and Client Secret from Zoom Marketplace)
  • OBS Studio 31+ with obs-spout2-plugin

Install

  1. Download and extract the ZoomToOBS release ZIP to a folder on your PC.
  2. Copy config.example.json to config.json in the same folder as zoom-bridge.exe.
  3. Generate a Meeting SDK JWT: 
    python generate_jwt.py --client-id YOUR_CLIENT_ID --client-secret YOUR_CLIENT_SECRET
  4. Paste the JWT into config.json as sdk_jwt.
  5. Run zoom-bridge.exe.

Note: ZoomToOBS is a standalone desktop app. End users do not install it from the Zoom Marketplace. You use your approved Zoom Meeting SDK credentials locally.

2. Using ZoomToOBS

Join a meeting

  1. Enter your Display name (shown in the meeting).
  2. Paste a Zoom invite link, or enter Meeting ID and passcode.
  3. Click Join meeting.
  4. When prompted in Zoom, the host must approve local recording.

Configure OBS capture

  1. After joining, select participants in Camera 1, optional Camera 2, and Screen share.
  2. Click Apply.
  3. In OBS, add Spout2 Capture sources:
    • ZoomToOBS_Camera — webcam
    • ZoomToOBS_Camera2 — second camera (optional)
    • ZoomToOBS_Share — screen share

Leave a meeting

  1. Click Leave in ZoomToOBS.
  2. Raw recording stops and Spout streams end.

3. Removing ZoomToOBS

  1. Click Leave if connected to a meeting.
  2. Close zoom-bridge.exe.
  3. Delete the application folder from your computer.
  4. Delete config.json (contains your JWT — do not share).
  5. Remove Spout2 Capture sources from OBS (optional).

No Zoom Marketplace uninstall is required — ZoomToOBS does not install as a Zoom Marketplace integration for end users.

4. Troubleshooting

  • Authentication failed — regenerate JWT; use Production credentials after app approval.
  • Error 63 (external meeting) — Zoom app must pass Marketplace review.
  • No video — host must approve recording; participant must have camera on.
  • Black share — participant is not sharing screen yet.
